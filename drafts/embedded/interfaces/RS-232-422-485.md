# Brief comparison of use cases of RS-232, RS-422, RS-485

# RS-232
- Full-duplex
- Point-to-point
- Unbalanced cables


# RS-422
**RS-422 makes the cables balanced.**

- Full-duplex
- Point-to-point (or unidirectional multidrop bus)
- Balanced cables


# RS-485
**RS-485 gives the ability to use it as a bus in half-duplex.**

- Multipoint mode:
  - Half-duplex
  - Balanced cables
- Point-to-point mode:
  - Full-duplex
  - Balanced cables
