**RS-485 (Recommended Standard 485)** is a hardware interface for distant,
serial communication. It uses twisted pairs with differential signaling.

**Way of use:**
- It's usually used for **multipoint** communication in **half-duplex** mode.
- It might be used for **multipoint** communication in **full-duplex** mode
  (usually with one master).
- It might be used for **point-to-point** communication in **full-duplex** mode.

RS-485 offers multipoint communication, but it doesn't provide any ways to
manage collision. So, the chosen protocol should resolve this problem.

# Physical characteristics
The interface doesn't define a maximum cable length or work speeds. But usually
it uses:
- Cables are less than 1200m long
- Baud rate may achieve up to 10MBd.

RS-485 interface can transmit data up to 35 Mbit/s or up to 1,200 meters with
lower rates (like 100 Kbit/s). Speed and length are inversely proportional to
each other.

The relative to the ground voltage is allowed in range from -7V to +12V.
**Voltage:**
Term    | Data signals | Differential voltage
--      | --           | --
Space   | 0            | +0.2V - +6V
Mark    | 1            | -6V - -0.2V
Invalid | -            | -0.2V - +0.2V

# Connections
**Topology:**  
The topology should consist of multidrop nodes, such as a line or a bus. A
star, ring or a multiply connected network are not recommended because of
signal reflections.

**Wires:**  
The wires should be terminated by termination resistors on any loose end.
Without termination resistors, unterminated ends might cause signal reflections.

**Pins:**
- Half-duplex:
  - DATA-B+, DATA-A-
  - GND
- Full-duplex:
  - TxD-B+, TxD-A-
  - RxD-B+, RxD-A-
  - GND

- Connectors are usually DE-9 or terminal blocks.
- Pinouts are manufacture-specific.
